## Decisions and rationale

- `data_fineweb_edu_gpt2_50m_v1` is the named preparation artifact. It streams the official 10B-token sample and stops after generating exactly 1,000,001 validation token IDs followed by 50,000,001 training token IDs.
- GPT-2 token IDs fit in `uint16`, so the frozen binaries require about 102 MB for training and 2 MB for validation. EOS is inserted and supervised after every nonempty document.
- `baseline_20m_fineweb_edu_50m_v1` is the full run; `baseline_20m_fineweb_edu_50m_v1_smoke` is a separate 65,536-target validation run with a separate output directory.
- The baseline has 7 decoder blocks, width 256, 8 heads, a 1024-unit SwiGLU MLP, RMSNorm, learned positions, tied GPT-2 embeddings, no linear bias, and a 512-token context.
- Checkpoints bind to configuration and dataset-manifest hashes. Committed targets define both the data cursor and learning-rate schedule, so checkpoints occur only at optimizer boundaries.
